👉 [**Download POS-System v1.0.0**](../../releases/latest)

## 🚀 Quick Start

1. Download `POS-System.zip`
2. Extract to any folder
3. Double-click `POS-System.exe`
4. Login with:
   - **Admin**: `admin` / `admin123`
   - **Cashier**: `cashier` / `cashier123`
5. **Change passwords immediately!**

## ✨ Features

- 🔐 Login System (Admin/Cashier)
- 📦 Product Management
- 🏷️ Barcode + QR Code Generation
- 📷 Camera Scan
- 📤 Sales (Split Payment + Hold)
- 📥 Purchases
- 💰 Udhaar Management
- 🏆 Loyalty Points
- 💵 Cash Drawer
- 📊 Dashboard + Reports
- 📝 Audit Log
- 🖨️ 80mm Thermal Print
- ☁️ Auto Backup
